# 8-Minute Demo Script

## 1. Business problem (60 sec)
IT teams lose time collecting evidence across identity, endpoint, network and knowledge systems. Routine incidents create queue pressure, while unsafe automation can create production risk.

## 2. Incident (60 sec)
Employee cannot connect to VPN. Launch the investigation.

## 3. Evidence collection (90 sec)
Show synthetic gateway, identity, MFA and client evidence. Emphasize that collection uses bounded tools and approved sources.

## 4. Grounded reasoning (90 sec)
Show the approved VPN runbook and probable root cause: stale client session.

## 5. Safe remediation (90 sec)
Show the low-risk allow-listed refresh action executing automatically.

## 6. Guardrail attack (90 sec)
Attempt `grant_admin` or `restart_production_service`. Show deterministic policy refusing autonomous execution and requiring approval.

## 7. Executive close (60 sec)
Lower MTTR and L1 volume without turning the LLM into a privileged administrator.
